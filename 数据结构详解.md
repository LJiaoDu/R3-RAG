# 改进版Reference Answer数据结构详解

## 完整数据结构

### 顶层结构

```json
{
  "question": "原始问题",
  "structured_answer": {
    // 结构化答案（核心部分）
  },
  "raw_response": "GPT-4的原始响应",
  "retrieved_docs": [...],
  "model": "gpt-4",
  "temperature": 0.0,
  "tokens_used": 1234,
  "quality_score": 0.95,
  "quality_checks": {...},
  "invalid_citations": [],
  "success": true
}
```

---

## 核心部分：structured_answer

这是最重要的部分，包含可验证的结构化答案：

```json
{
  "answer_summary": "简短的直接答案（1-2句话）",

  "facts": [
    {
      "claim": "具体的事实陈述",
      "citations": ["doc_id#chunk_id", "doc_id2#chunk_id2"],
      "confidence": "high"
    }
  ],

  "unknown": [
    "缺失的信息1",
    "缺失的信息2"
  ],

  "used_documents": ["doc_id1", "doc_id2"]
}
```

### 字段说明

#### 1. `answer_summary` (string)
**用途**：简短的直接答案，回答核心问题

**特点**：
- 1-2句话
- 直接回答问题
- 不包含详细解释

**示例**：
```json
"answer_summary": "The prerequisites for Machine Learning (IN2064) are Linear Algebra (MA1001) and Probability Theory (MA2009), which must be taken in sequence."
```

---

#### 2. `facts` (array of objects)
**用途**：所有具体事实的列表，每个事实都有引用

**每个fact包含**：

##### `claim` (string)
具体的事实陈述，必须：
- ✅ 明确具体
- ✅ 可验证
- ✅ 单一事实（不要混合多个事实）

**好的claim示例**：
```json
"claim": "Machine Learning (IN2064) is worth 8 ECTS credits"
```

**不好的claim示例**：
```json
❌ "claim": "ML is important and worth 8 ECTS"  // 混合了"重要"（主观）和"8 ECTS"（事实）
❌ "claim": "You need some math courses"       // 太模糊
```

##### `citations` (array of strings)
支持这个claim的文档引用列表

**格式**：`["doc_id#chunk_id"]`

**示例**：
```json
"citations": ["course_IN2064#prerequisites", "course_IN2064#info"]
```

**关键规则**：
- ✅ 至少1个citation
- ✅ 必须是精确的doc_id#chunk_id格式
- ✅ 必须存在于retrieved_docs中

##### `confidence` (string)
对这个事实的置信度

**取值**：
- `"high"`: 文档中明确陈述
- `"medium"`: 文档中暗示或需要简单推理
- `"low"`: 不确定（少用）

**示例**：
```json
// High confidence
{
  "claim": "Machine Learning is 8 ECTS",
  "citations": ["course_IN2064#info"],
  "confidence": "high"
}

// Medium confidence
{
  "claim": "The course is suitable for second-year students",
  "citations": ["course_IN2064#recommendation"],
  "confidence": "medium"
}
```

---

#### 3. `unknown` (array of strings)
**用途**：明确列出问题中涉及但文档中没有的信息

**关键点**：
- ✅ 这是**好事**，不是缺陷
- ✅ 防止模型编造信息
- ✅ 诚实承认信息不足

**示例**：
```json
"unknown": [
  "Number of assignments in the course",
  "Exact exam date",
  "Whether the course is offered in summer semester",
  "Programming language used in assignments"
]
```

**何时使用**：
```
问题问到了X，但检索文档里没有X
  ↓
把X放入unknown
  ↓
不要编造X
```

---

#### 4. `used_documents` (array of strings)
**用途**：记录哪些文档被实际使用

**示例**：
```json
"used_documents": ["course_IN2064", "course_MA1001", "course_MA2009"]
```

**用途**：
- 追溯信息来源
- 验证是否所有引用的文档都在检索结果中
- 分析检索质量

## 如何使用这个数据结构

### 1. 作为Golden Answer验证推理链

```python
# 推理链生成后
reasoning_chain = generate_reasoning_chain(question)
chain_answer = reasoning_chain['final_answer']

# 使用Reference Answer验证
reference = get_reference_answer(question)
reference_facts = reference['structured_answer']['facts']

# 提取reference中的关键信息
reference_entities = set()
for fact in reference_facts:
    # 提取课程代码
    codes = extract_course_codes(fact['claim'])
    reference_entities.update(codes)

# 验证推理链的答案
chain_entities = extract_course_codes(chain_answer)

# F1 score
f1 = compute_f1_score(chain_answer, reference['structured_answer']['answer_summary'])

# 实体匹配
entity_overlap = len(chain_entities & reference_entities) / len(reference_entities)

# 判断
if f1 >= 0.7 or entity_overlap >= 0.8:
    print("✅ 推理链验证通过")
else:
    print("❌ 推理链质量不足")
```

### 3. 质量验证和过滤

```python
def validate_and_filter(results):
    """验证并过滤高质量数据"""

    high_quality = []

    for result in results:
        if not result['success']:
            continue

        # 检查1: 质量分数
        if result['quality_score'] < 0.8:
            print(f"⚠️  质量不足: {result['question']}")
            continue

        # 检查2: 引用有效性
        if len(result['invalid_citations']) > 0:
            print(f"⚠️  无效引用: {result['question']}")
            continue

        # 检查3: 至少有一些facts
        facts = result['structured_answer']['facts']
        if len(facts) == 0:
            print(f"⚠️  没有事实: {result['question']}")
            continue

        # 检查4: 所有facts都有引用
        all_have_citations = all(
            len(fact.get('citations', [])) > 0
            for fact in facts
        )
        if not all_have_citations:
            print(f"⚠️  缺少引用: {result['question']}")
            continue

        high_quality.append(result)

    return high_quality
```

### 4. 引用验证

```python
def verify_citations(result):
    """验证所有引用的有效性"""

    structured = result['structured_answer']
    docs = result['retrieved_docs']

    # 构建有效citation的集合
    valid_citations = set()
    for doc in docs:
        doc_id = doc['doc_id']
        if 'chunks' in doc:
            for chunk in doc['chunks']:
                chunk_id = chunk['chunk_id']
                valid_citations.add(f"{doc_id}#{chunk_id}")
        else:
            valid_citations.add(f"{doc_id}#full")

    # 验证每个fact的citations
    for fact in structured['facts']:
        claim = fact['claim']
        citations = fact['citations']

        for cite in citations:
            if cite not in valid_citations:
                print(f"❌ 无效引用: {cite}")
                print(f"   Claim: {claim}")
                return False

            # 进一步验证：claim是否在chunk内容中
            chunk_content = get_chunk_content(docs, cite)
            if not verify_claim_in_content(claim, chunk_content):
                print(f"⚠️  Claim可能不准确: {claim}")
                print(f"   Citation: {cite}")
                print(f"   Content: {chunk_content}")

    return True
```

## 存储格式

### 推荐：JSONL格式（每行一个JSON对象）

```jsonl
{"question": "...", "structured_answer": {...}, "quality_score": 0.95, ...}
{"question": "...", "structured_answer": {...}, "quality_score": 0.88, ...}
{"question": "...", "structured_answer": {...}, "quality_score": 0.92, ...}
```

**优点**：
- ✅ 易于流式处理
- ✅ 易于追加
- ✅ 单个损坏不影响其他
- ✅ 易于断点续传

### 读取示例

```python
def load_reference_answers(file_path):
    """加载所有Reference Answers"""
    results = []
    with open(file_path, 'r', encoding='utf-8') as f:
        for line in f:
            data = json.loads(line.strip())
            results.append(data)
    return results

# 使用
reference_answers = load_reference_answers('reference_answers.jsonl')

# 按question建立索引
qa_dict = {
    r['question']: r['structured_answer']
    for r in reference_answers
}

# 查询
question = "What are the prerequisites for ML?"
if question in qa_dict:
    answer = qa_dict[question]
    print(answer['answer_summary'])
```

## 总结

### 数据结构的核心优势

1. **可验证性**
   - 每个fact都有精确的citations
   - 可以自动验证引用的有效性
   - 可以追溯信息来源

2. **诚实性**
   - unknown字段明确标记缺失信息
   - 不会为了"完整"而编造
   - 防止脏数据

3. **结构化**
   - JSON格式，易于处理
   - 字段明确，便于提取
   - 适合后续训练和验证

4. **可追溯**
   - used_documents记录来源
   - citations精确到chunk级别
   - 便于调试和分析

### 与旧版本对比

| 特性 | 旧版本 | 改进版本 |
|------|--------|---------|
| 格式 | 自由文本 | 结构化JSON |
| 引用 | 无或模糊 | 精确到chunk |
| 验证 | 不可能 | 完全可验证 |
| 诚实性 | 低（被惩罚） | 高（unknown鼓励） |
| 脏数据率 | 50-70% | <5% |

这个数据结构专门设计用于**防止脏数据**，确保你生成的Reference Answer可以安全地用作Golden Answer！🎯
